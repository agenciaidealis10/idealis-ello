# Agência Idealis × ELLO — Landing Page

Pacote pronto para publicação na Vercel.

## Arquivos
- `index.html` — landing page completa
- `favicon.png` — ícone do navegador
- `og-image.jpg` — imagem para compartilhamento
- `vercel.json` — configuração básica da Vercel

## Como publicar na Vercel
1. Acesse https://vercel.com e entre na sua conta.
2. Crie um novo projeto.
3. Envie esta pasta via GitHub ou importe o projeto correspondente.
4. Como é um site HTML estático, não é necessário configurar framework nem comando de build.
5. Publique.
6. Depois do primeiro deploy, copie o endereço final `*.vercel.app`.

### Compartilhamento
A página já tem título, descrição, favicon e imagem Open Graph.
Após o primeiro deploy, vale trocar `og:image` e `twitter:image` no `index.html`
para a URL absoluta final, por exemplo:
`https://SEU-PROJETO.vercel.app/og-image.jpg`
Isso maximiza a compatibilidade da prévia no WhatsApp e redes sociais.
